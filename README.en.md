# OpenX

[简体中文](README.md) | **English**

OpenX = [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) × [OpenHarmony](https://gitcode.com/openharmony/manifest)

OpenX is an operating system that has DeepSeek Harness at its core, uses OpenHarmony for system capabilities, and follows the "**Everything is a Plugin**" principle.
